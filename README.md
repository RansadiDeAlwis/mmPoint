# mmPoint: Dense Human Point Cloud Generation from mmWave Radar

This repository is a reproduction and research implementation of  
[**mmPoint: Dense Human Point Cloud Generation from mmWave Radar (BMVC 2023)**](https://github.com/NUAAXQ/mmPoint),  
originally by **Qian Xie et al.** (University of Oxford, MIT, and University of Cape Town).

mmPoint is the **first model** capable of generating **dense human point clouds** from single-frame mmWave radar signals using an encoder-decoder network with multi-modal fusion and progressive deformation.

---

## Overview

Millimeter-wave (mmWave) radar enables non-intrusive and privacy-preserving 3D sensing.  
However, radar-generated point clouds are inherently **sparse and noisy**, limiting their use in fine-grained human analysis.

**mmPoint** tackles this by:
- Taking a single radar signal frame as input  
- Combining it with a template human point cloud  
- Generating a **dense, structured, and high-fidelity point cloud** representing the human body  

The model uses a **Multi-Modal Encoder (MME)** and a **Multi-Resolution Decoder (MRD)** with **Lift-and-Deform Modules (LDM)** to progressively refine the point cloud.

---

## Architecture

### Main Components

**Multi-Modal Encoder (MME)**  
- Encodes radar tensor and point cloud template  
- Employs MNet-based mmWave encoder and EdgeConv-based point cloud encoder  

**Multi-Resolution Decoder (MRD)**  
- Uses a three-step deformation process to upsample and refine the point cloud  
- Each step doubles point density using Lift-and-Deform Modules  

**Lift-and-Deform Module (LDM)**  
- “Lifts” the point density by upsampling  
- “Deforms” it using learned displacements conditioned on radar features

## Dataset

This project uses an adapted version of the **HuPR dataset** from the paper  
[*HuPR: A Benchmark for Human Pose Estimation using mmWave Radar*](https://openaccess.thecvf.com/content/WACV2023/html/Lee_HuPR_A_Benchmark_for_Human_Pose_Estimation_Using_Millimeter_Wave_Radar_WACV_2023_paper.html).

- **Radar used:** TI IWR1843BOOST  
- **Total samples:** 200+ synchronized radar and image sequences  

Ground-truth dense human point clouds are generated by:
1. Extracting 2D poses using **OpenPose**  
2. Converting 2D skeletons to 3D meshes using **Expressive Body Capture (ExBodyCap)**  
3. Sampling 3D points from reconstructed meshes for supervision  

Each dataset pair consists of:
- mmWave radar tensor (shape: `16×64×64×8`)  
- Dense ground-truth human point cloud (~2048 points)
